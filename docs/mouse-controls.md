# Keyboard and mouse controls

In the ESC menu, enable **Free camera look** and **Mouse camera and combat** under Controls. **Mouse sensitivity** adjusts both camera movement and item aiming. The game must use its button-only control mode.

| Input | Action |
| --- | --- |
| Mouse movement | Turn the camera. |
| Hold left click and move | The mouse becomes the sword stick: a flick swings that way (any of 8 directions), circles and holds work like the game's own right-stick gestures. Releasing recentres it. |
| Left click without moving | Horizontal slash. |
| Right click | Hold target lock; pressing also sends a shield bash. A shield must be equipped. |
| Middle click | Sword thrust. |
| Hold Left Alt or Mouse 4 | Item aiming mode. Mouse movement controls the item's aim instead of the camera or sword. |
| Left click in item aiming mode | Sends ZR: ready/use the selected item. With the bow ready, hold to draw and release to fire. |
| Hold 3 and move the mouse | Select an item from the game's item wheel (default ZR binding). |
| Hold Mouse 5 or E and move the mouse | Open/select from the adventure pouch (R). |
| WASD | Move Link. |
| K / J | Interact or sprint / cancel or put away (A / B). |
| Q | Tap to switch free camera mode; hold temporarily for the original sword-stick behavior. |
| Esc | Open the port's menu and release the cursor. |

The existing keyboard and controller bindings remain available. Explicit mouse button bindings take precedence over these combat shortcuts. Disabling mouse controls restores ordinary cursor behavior. Losing window focus, opening the menu or returning to the launcher clears mouse buttons and pending attacks.

Mouse movement uses the game's analog-stick camera and aiming behavior, including its maximum turn speed. It does not provide a separate first-person shooter camera.

# Changing the game's language

Choose **Language** in the ESC menu. The selection is saved immediately. If a game is running, **Apply language and restart...** reloads the game with the selected language after confirmation. Save first: progress since the last save is lost. Canceling keeps playing without restarting; the saved language applies on the next boot.

The port's own menu remains in English. The language option selects the game's supplied text languages.
